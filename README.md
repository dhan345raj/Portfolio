## 🚀 Running Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/dhan345raj/Portfolio.git
   cd Portfolio
   ```
2. Open with any local HTTP server:
   ```bash
   # Using Python 3
   python -m http.server 8000
   
   # Or using Node npx
   npx serve .
   ```
3. Open `http://localhost:8000` in your web browser.
